## Description

OpenMatch turns a resume and job description into an explainable fit report,
truthful resume improvements, and a role-specific interview studio. GPT-6 Astra
adds contextual analysis, follow-up questions, and answer feedback. A transparent
local engine keeps the full workflow explorable without an API key.

## First comment

Hi Product Hunt 👋

I built OpenMatch because job-search AI often hands people a confident score
without showing the evidence behind it. That makes it hard to know what to trust
or what to improve.

OpenMatch works differently. Upload a resume and role description to get:

- an explainable, weighted match report with supporting resume evidence;
- honest gap analysis and resume suggestions that avoid inventing experience;
- STAR story and role-specific question prep;
- an interview studio with typed or spoken answers, follow-ups, wording notes,
  pace feedback, and downloadable notes; and
- a recruiter view that compares candidates against the same criteria and keeps
  email feedback human-reviewed.

For the GPT-6 Astra Challenge, I wired the OpenAI path to `gpt-6-astra` through
the Responses API with structured outputs. Astra handles deeper resume-to-role
reasoning and contextual interview coaching. The deterministic local engine
remains available so the complete interface can be explored without an API key,
and every result is labeled by engine.

The app is open source. I would especially value feedback on the evidence-first
report, the interview practice loop, and whether the product earns your trust.

Thanks for taking a look.
